# 🌦️ Atmospheric Dashboard

A modern, Google Material You-inspired weather dashboard built with **HTML**, **CSS**, and **JavaScript**. It provides real-time weather information through the OpenWeatherMap API with a clean, responsive bento-style interface.

## ✨ Features

- 🌍 Search weather by city
- 📍 Get weather using your current location
- 🌡️ Real-time temperature and weather conditions
- 📈 24-hour temperature forecast chart
- 📅 5-day weather forecast
- 🌧️ Live precipitation radar
- 💧 Humidity
- 💨 Wind speed and direction
- 👀 Visibility
- ☀️ Optional UV Index support
- 📱 Fully responsive Material You-inspired UI

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
- Tailwind CSS
- Google Material Symbols
- OpenWeatherMap API

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/sarvasya/atmospheric-dashboard.git
```

2. Open the project folder.

3. Add your OpenWeatherMap API key in `script.js`:

```javascript
const API_KEY = "YOUR_OPENWEATHERMAP_API_KEY";
```

4. Open `index.html` in your browser or use the **Live Server** extension in VS Code.

## 🌐 APIs Used

- Current Weather API
- 5 Day / 3 Hour Forecast API
- Weather Maps API
- One Call API 3.0 (Optional for UV Index)
